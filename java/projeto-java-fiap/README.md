# Nano FIAP Produto

Primeiro projeto desenvolvido em Java durante os estudos na FIAP.

## Tecnologias utilizadas

- Java 2
- Maven
- Programação Orientada a Objetos (POO)

## Estrutura do projeto

src/main/java/br/com/fiap/produtos

**model**
- Categoria.java
- Produto.java

**repository**
- CategoriaCollectionRepository.java
- ProdutoCollectionRepository.java

**view**
- Main.java
- Opcao.java
- OpcaoView.java
- ProdutoView.java

## Objetivo

Aplicar conceitos de Java, orientação a objetos, organização de código e desenvolvimento de uma aplicação utilizando Maven.
