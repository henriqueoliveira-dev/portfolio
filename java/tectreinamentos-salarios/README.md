# Sistema de Cálculo de Salários

Projeto desenvolvido em Java com interface gráfica utilizando Eclipse.

## Sobre o projeto

Sistema desenvolvido para realizar cálculos relacionados a salários através de uma interface gráfica.

## Tecnologias utilizadas

- Java
- Programação Orientada a Objetos
- Interface gráfica
- Eclipse IDE

## Estrutura

- src/ - Código-fonte do projeto
- in/ - Arquivos compilados, ignorados pelo Git
- .project - Configuração do projeto Eclipse
- .classpath - Configuração do classpath do Eclipse

## Objetivo

Projeto desenvolvido como prática de programação Java e desenvolvimento de aplicações com interface gráfica.
