# Conceitos básicos

## Banco de dados

Um banco de dados armazena e organiza informações para que possam ser consultadas e manipuladas.

## Tabela

Uma tabela organiza os dados em linhas e colunas.

## PRIMARY KEY

Identifica de forma única cada registro de uma tabela.

## FOREIGN KEY

Cria uma ligação entre tabelas e representa um relacionamento entre dados.

## Relacionamento

Neste projeto:

- Um autor pode possuir vários livros.
- Cada livro está relacionado a um autor.

Representação:

```text
AUTOR 1 -------- N LIVRO
```

## INNER JOIN

O `INNER JOIN` permite combinar registros relacionados de duas ou mais tabelas.
