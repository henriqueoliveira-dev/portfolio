# Introdução a Banco de Dados

Projeto prático para estudar os fundamentos de bancos de dados relacionais e SQL.

## Conteúdos

- Criação de banco de dados
- Criação de tabelas
- PRIMARY KEY
- FOREIGN KEY
- Relacionamentos
- INSERT
- SELECT
- UPDATE
- DELETE
- INNER JOIN

## Banco utilizado

MySQL / MariaDB

## Objetivo

Aprender os fundamentos de SQL e bancos de dados relacionais através de um projeto prático.
