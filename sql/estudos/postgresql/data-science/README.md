# PostgreSQL — Data Science

Projeto de estudos práticos em PostgreSQL, desenvolvido para praticar modelagem de banco de dados, criação de tabelas, relacionamentos e estruturação de dados.

## Banco de dados

Projeto desenvolvido no PostgreSQL.

## Estrutura

O schema contém 8 tabelas:

- departamentos
- funcionarios
- localizacao
- maquinas
- filme
- genero
- locacao
- rel_locadora

## Conteúdos praticados

- CREATE TABLE
- Chaves primárias
- Chaves estrangeiras
- Relacionamentos entre tabelas
- Tipos de dados
- Restrições
- Modelagem relacional
- Organização de schema

## Arquivo SQL

O arquivo sql/01_schema.sql contém a estrutura do banco de dados gerada a partir do PostgreSQL.

## Objetivo

Registrar e organizar os estudos práticos de PostgreSQL para composição do meu portfólio técnico em bancos de dados.
