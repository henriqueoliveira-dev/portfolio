# Portfólio de Estudos em SQL

Repositório dedicado aos meus estudos práticos em bancos de dados relacionais, com exercícios, consultas, modelagem, procedures, triggers e projetos utilizando MySQL, PostgreSQL e SQL Server.

## Bancos de Dados

### MySQL

Projetos e exercícios envolvendo criação de bancos, tabelas, relacionamentos, consultas, JOINs, manipulação de dados e Stored Procedures.

- mysql/introducao-banco-de-dados
- mysql/comercio-db

### PostgreSQL

Projeto prático de estruturação e modelagem de banco de dados utilizando PostgreSQL.

- postgresql/data-science

### SQL Server

Estudos práticos envolvendo consultas, exercícios, JOINs, Stored Procedures e Triggers.

- sql-server/consultas
- sql-server/exercicios
- sql-server/joins
- sql-server/procedures
- sql-server/triggers

Este repositório faz parte do meu portfólio técnico e registra minha evolução prática no desenvolvimento e administração de bancos de dados relacionais.
