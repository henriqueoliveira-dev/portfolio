# Estruturas de Programação em Python

Material de estudos sobre estruturas condicionais e laços de repetição em Python. O conteúdo foi separado em arquivos independentes para facilitar a leitura, a execução e a evolução do repositório.

## Conteúdo

- **Condicionais:** `if`, `else`, `elif`, comparações, operadores lógicos, condições aninhadas e exercícios práticos.
- **Laços `while`:** contadores, leitura de valores, `break`, `continue` e processamento de textos.
- **Laços `for`:** `range`, iteração em strings, laços aninhados, tabuada e exercícios.

## Estrutura do projeto

```text
estruturas-programacao/
├── README.md

```

## Tecnologias

- Python 3.8 ou superior

Não há dependências externas de Python.

## Como executar

Cada arquivo `.py` é um exemplo independente. A partir da raiz do projeto, execute, por exemplo:

```bash
python3 condicionais/11_par_ou_impar.py
python3 lacos/while/08_media_de_valores.py
python3 lacos/for/09_tabuada.py
python3 lacos/exercicios/05_numeros_primos.py
```

O arquivo `lacos/while/01_laco_infinito.py` é apenas uma demonstração. **Não o execute normalmente**, pois ele imprime continuamente até ser interrompido manualmente.

## Ajustes realizados

A lógica dos exemplos foi preservada. Foram feitos somente ajustes necessários para organização, segurança e execução: substituição dos dados fictícios de senha e CPF, correção da ordem da classificação de idade, validação de divisão por zero, conversão da quantidade de repetições para inteiro, correção do avanço do índice na contagem de espaços e correções pontuais de mensagens.

O notebook original não faz parte desta publicação. Ele foi mantido separadamente no arquivo anexado original.

## Objetivo de aprendizagem

Praticar decisões condicionais, repetição controlada, leitura de dados, operadores, contadores, acumuladores, interrupção de laços e resolução de exercícios introdutórios.
