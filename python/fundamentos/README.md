# Python Fundamentos



Material introdutório de estudos e exercícios práticos sobre fundamentos da linguagem Python, organizado por tópicos.



## Estrutura



- `01_introducao/`: comentários e saída com `print`;
- 
- `02_variaveis_tipos/`: variáveis e tipos primitivos;
- 
- `03_formatacao/`: formatação de textos e números;
- 
- `04_operadores/`: operadores aritméticos, lógicos e de comparação;
- 
- `05_casting/`: conversão de tipos e valores booleanos;
- 
- `06_entrada_dados/`: entrada de dados com `input`;
- 
- `07_strings/`: operações e manipulação de strings;
- 
- `exemplos/`: exemplo completo reunindo os fundamentos.
- 


## Requisitos



Python 3.8 ou superior. O projeto utiliza somente a biblioteca padrão.



## Como executar



Execute qualquer módulo diretamente, por exemplo:



```bash

python3 01_introducao/comentarios_print.py

python3 exemplos/python_fundamentos_completo.py

```



Os exemplos são educacionais e podem ser alterados livremente para acompanhar os estudos.
