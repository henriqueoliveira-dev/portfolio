# Comandos Básicos do Linux

## ls

Lista os arquivos e diretórios.

```bash
ls
ls -l
ls -lh
ls -la
```

---

## pwd

Mostra o diretório atual.

```bash
pwd
```

---

## cd

Navega entre diretórios.

```bash
cd Documentos
cd ..
cd ~
cd /
```

---

## mkdir

Cria diretórios.

```bash
mkdir projetos
```

---

## touch

Cria arquivos vazios.

```bash
touch arquivo.txt
touch script.sh
```

---

## cp

Copia arquivos.

```bash
cp arquivo.txt backup.txt
```

---

## mv

Move ou renomeia arquivos.

```bash
mv arquivo.txt novo_nome.txt
```

---

## rm

Remove arquivos ou diretórios.

```bash
rm arquivo.txt
rm -r pasta
rm -rf pasta
```

---

## cat

Exibe o conteúdo de um arquivo.

```bash
cat arquivo.txt
```

---

## echo

Exibe texto ou grava conteúdo.

```bash
echo "Olá Linux"
```

---

## df

Mostra o uso do espaço em disco.

```bash
df -h
```

---

## Resumo

| Comando | Função                   |
| ------- | ------------------------ |
| ls      | Lista arquivos           |
| pwd     | Mostra o diretório atual |
| cd      | Navega entre diretórios  |
| mkdir   | Cria diretórios          |
| touch   | Cria arquivos            |
| cp      | Copia arquivos           |
| mv      | Move ou renomeia         |
| rm      | Remove arquivos          |
| cat     | Mostra conteúdo          |
| echo    | Exibe texto              |
| df      | Mostra espaço em disco   |
