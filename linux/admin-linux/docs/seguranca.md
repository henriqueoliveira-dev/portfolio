# Segurança

Princípios do laboratório: menor privilégio, atualização, senhas fortes, contas individuais, SSH restrito, firewall, logs e backups testados.

Antes de publicar, procure por `.env`, tokens, chaves privadas, strings de conexão e dados pessoais. Use variáveis de ambiente para credenciais e mantenha `.env` fora do Git.
