# Instalação e preparação

Use uma máquina virtual ou ambiente de laboratório. Registre a distribuição e a versão antes de estudar:

```bash
cat /etc/os-release
uname -a
```

Mantenha snapshots quando usar uma VM. Não copie credenciais para scripts. Os exemplos priorizam Debian/Ubuntu; consulte `distribuicoes.md` para diferenças com RHEL/Fedora.
