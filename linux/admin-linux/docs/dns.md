# DNS — planejado

DNS traduz nomes em endereços e usa registros como A, AAAA, CNAME e MX. Estudar resolução com:

```bash
getent hosts example.com
resolvectl status
``

A configuração de um servidor DNS ainda é uma etapa planejada deste laboratório. Registre o ambiente e valide mudanças antes de aplicá-las.
